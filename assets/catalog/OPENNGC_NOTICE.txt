Changes made for AstroPlan: a selection of 164 objects (the Messier objects
present in OpenNGC and a list of well-known imaging targets); coordinates
converted from sexagesimal to decimal degrees; OpenNGC object types mapped to
the app's target types; only the name, type, J2000 coordinates, major axis
(arcmin), V magnitude and first common name are kept; identifiers
reformatted (e.g. NGC0224 -> M31 or NGC 224). The adapted catalog file is
licensed under CC BY-SA 4.0 as well.
