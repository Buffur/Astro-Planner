# Culmina

Culmina is a free, open-source astrophotography planner for Android: build a realistic capture
plan for a target, see whether it fits the night, and keep a logbook of what you captured. It has
no account, no advertising and no tracking, and it works offline.

- [Privacy policy](privacy/)
- [Source code (GPL-3.0)](https://github.com/Buffur/Culmina)
- Releases: signed APKs on the repository's [Releases](https://github.com/Buffur/Culmina/releases) page

Earlier builds were named Astro Planner.
