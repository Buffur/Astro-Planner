# Scientific Calculation Rules

- Every non-trivial calculation must document purpose, inputs, units, formula,
  assumptions, output, valid range, edge cases, reference/source, and tests.
- Do not invent sensor specifications, astronomical constants, catalog values,
  API fields, or file-format behavior.
- Label relative stacking gain as relative stacking gain, not absolute SNR.
- Distinguish theoretical storage payload from empirical file-size estimates.
- Present NPF as a recommendation only after the selected model is documented
  and tested.
