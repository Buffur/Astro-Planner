# UI Design Rules

- Prefer a clean, minimalist, information-dense interface.
- Avoid decorative astronomy artwork, excessive animation, and generic
  space-themed visual clutter.
- Keep field use in mind: readability, clear hierarchy, and simple navigation.
- Do not prematurely implement field utilities outside their approved phase.
- Use UI elements for functional purpose, not decoration.

- Product Reassessment may propose changes to hierarchy, branding and feature prominence. Proposals are not implementation approval.
- Purposeful, restrained transitions or a branded loading state are allowed within approved design scope; respect reduced motion, accessibility and startup performance. The prohibition on excessive animation is not a blanket ban on animation.
