# Project Governance Rules

- Treat the roadmap phase as the active scope.
- Do not implement future-phase functionality without explicit approval.
- Do not silently alter product scope, architecture, database design, or
  dependencies.
- For multi-file, architectural, database, or scope-affecting work, inspect,
  report a plan, and wait for approval before implementation.
- Distinguish verified facts, assumptions, recommendations, and unresolved
  risks.
